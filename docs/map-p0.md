### 判断のお願い（代表点の方針）
- **A（依頼どおり・既定）**: `representative_point()` を採用。`method=n03_representative_point`。上記6市町村は円が市街地から外れて見える可能性。

**ETL の変更**: `build.py` に `annual_category.json` 出力を追加。座標生成は冪等（N03 原データ固定＋決定的アルゴリズム）。
**フロントの変更**: `main.ts` から状態・色を切り出し（挙動不変のリファクタ）。タブ UI を追加。既存モードは触らない。

**UI**: 上部にタブ「レース｜地図」。地図タブの操作: 指標（月別／年間／分類別（年間）＋分類選択）、再生・スライダー・速度は**レースと共有**（`state.ts` の `(year, month)`。分類別は年のみ動く）。
円は地域色・半透明 0.5＋白細線、半径 `r = r_max × sqrt(v / v_max)`（`v_max`=選択指標の全期間最大。最小 3px、0 は輪郭のみ、null は描画しない）、
`circle-sort-key` で大きい円ほど下、`circle-radius-transition` でなめらかに。ポップアップ（名称・値・地域・順位・前年同月比）、タップ領域 44px 以上、凡例（基準円3つ・折りたたみ）、下部に降順テーブル、
常時表示: 「円の位置は市町村の代表点です。観光地点の位置ではありません」＋出典（県／地理院タイル／国土数値情報・加工表記）＋「国・県が作成・保証したものではない」＋推計値の注意。

**スケールの注意**: `v_max`（全期間の最大値）は月別 **新潟市 2015年8月 約331万**、年間 **新潟市 2015年 約2,006万**、分類別（年間）**新潟市「行祭事・イベント」2015年 約773万**で、指標ごとに別になるため、指標を切り替えると円の絶対的な大きさは比較できない。画面に「基準: 選択指標の全期間最大」と明示し、凡例の基準円も指標に合わせて変える。レンジは非常に大きい（月別の最小は粟島浦村 2024年3月の 5人。年間でも新潟市 2,006万 対 粟島浦村 約1.1万で約1,800倍）。半径は √ なので最大/最小の比は約40〜1,000倍で、小さい村は最小半径 3px に張り付く。実装後に見え方を確認して調整案を提示する。

**テスト方針**: 
- ETL（pytest）: 30/30 座標、代表点が N03 の対応ポリゴン内、全点が新潟県の範囲内、`monthly.json` の全市町村が座標と結合可能、冪等（2回実行で同一）、override が反映される。
- フロント: `radius.ts` を純関数にして単体テスト（面積比例（クランプ内）、単調増加、0・null）。Vite 付属では無いため **vitest を devDependency に追加**（要承認）。既存の 11 テストと `tsc`/`vite build` を毎回実行。
- 手動確認手順を README に記載（スマホ Safari/Chrome、再生中、凡例位置、タップ当たり判定）。

## 10. 結果の確認方法
